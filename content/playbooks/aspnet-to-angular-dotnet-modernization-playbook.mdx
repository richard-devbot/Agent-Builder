# ASP.NET to Angular + .NET Web Modernization Playbook

A multi-quarter playbook for migrating a legacy ASP.NET web application (WebForms or MVC) to a modern Angular SPA + .NET API architecture using the strangler fig pattern. Click through the 9 phases — each one points you at the right templates, skills, and MCP configs to use in your IDE, with a clear definition-of-done before you move on.

## When to use this playbook

- You have an ASP.NET WebForms, MVC 4-5, or older .NET web app
- The app must keep running while you migrate (you can't stop business)
- You want to end up with: Angular SPA frontend + modern .NET REST APIs + clean data layer
- Migration timeline is multiple quarters (anything &lt;3 months should question scope)

## Don't compress this

The teams that succeed at modernization spend the time. The teams that fail try to compress the schedule by skipping phases — usually the audit, the parity tests, or the coexistence infrastructure. Each skipped phase becomes incidents and delays later.

If leadership pushes for faster, the conversation isn't "skip phases" — it's "scope down to a smaller migration." Migrate fewer slices. Defer non-critical capabilities. But don't skip the foundation.

## Independent of the Custom Web App playbook

This playbook is for **modernizing existing systems**. If you're starting from scratch, use the [Custom Web App Playbook](/playbook/custom-web-app) instead. The two playbooks share some templates (ADRs, OpenAPI, code review) but the sequence and emphasis are completely different.
